Script & auto-edit

Add the main track and the script with editing instructions, then generate the edit. Review it in the Editor tab.

1Main track

The conversation file from ElevenLabs or Google TTS: WAV, MP3, M4A, OGG, FLAC, or the audio of an MP4/MOV. Pauses between speakers line the script up with the audio; a subtitle file gives exact timings.

2Script with editing instructions

Supported instruction tags

Speaker lines: NAME: text. Instructions in square or curly brackets, on their own line (applies to the next line) or inside a line (start = before, end = after):
[INTRO MUSIC] [OUTRO MUSIC] [SFX: whoosh] [EMOTION: laugh] [TRANSITION] [POSITIONING MUSIC START] … [POSITIONING MUSIC END] [BGM START] … [BGM END].
Voice-direction tags such as [laughs] or [whispers] are left to the TTS and not treated as edits.

Mix settings used when placing sounds
